WhatsApp Business Messaging

PendoAdmin WhatsApp microservice + SnB core banking integration — Pendo Media Ltd (2026)

SACCOs wanted to reach their members on WhatsApp, not only by SMS. I led the development of the whole path: onboarding a business's WhatsApp account, managing Meta-approved message templates, billing each message to the tenant's wallet, and sending, scheduling and tracking every message from inside SnB, with SMS as the fallback.

What I Built

1 · Onboarding

Meta Embedded Signup and OAuth flow backed by a state machine and nonces, automatic token-health checks and 50-day token rotation, and app settings stored securely in the database.

Meta OAuth Schedulers

2 · Templates

Unified template builder with named placeholders, multi-account template sync, edit-in-place resubmission of rejected templates, rejection-reason sync and an in-app Meta compliance guide, plus a default notification catalog for SnB.

Meta Cloud API Vue 3

3 · Send & Bill

Queued outbox with atomic send-claims and a scheduled-send sweeper, CSV/Excel bulk compose, and per-category pricing debited from each tenant's wallet, with a shared-account fallback for new tenants.

RabbitMQ Laravel Queues

4 · Track & Fall Back

Delivery-status webhooks plus polling reconciliation with a status mapper, and WhatsApp OTP for member logins that falls back to SMS automatically when WhatsApp isn't available.

Webhooks SMS Fallback
